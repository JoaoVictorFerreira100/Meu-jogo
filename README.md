Sonic Retro Runner

Por João Victor Ferreira

Jogo de corrida inspirado no clássico jogo do dinossauro do navegador, usando os personagens de sonic. Feito com HTML, CSS e JavaScript puro.

Como jogar
- Pressione **Espaço** ou **Seta para cima** para pular.
- No celular, toque na área do jogo.
- Pule sobre os inimigos que aparecem no chão.
- Evite os inimigos que aparecem no ar: encostar neles também encerra a partida.
- Depois de perder, use **JOGAR NOVAMENTE** para recomeçar.
